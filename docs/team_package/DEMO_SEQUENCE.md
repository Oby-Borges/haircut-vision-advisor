# Suggested Demo Sequence

1. Boot main controller.
2. Show calibration status + Safe Home.
3. Show gyro/manual motion.
4. Boot separate camera node.
5. Show live camera feed.
6. Start a session in App.
7. Perform head scan.
8. Answer haircut questions.
9. Generate/select haircut.
10. Show mapped AR haircut on head.
11. Show head tracking values updating.
12. Show planned robot path in dry-run/preview.
13. Demonstrate Teach or safe automated path on a mannequin.
14. Demonstrate tracking-loss pause and E-stop.

Keep the demo modular: if Auto is not physically ready, the AR/map + validated path preview is still demonstrable independently.
